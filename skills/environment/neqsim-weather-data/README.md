# neqsim-weather-data

Live, forecast and historical weather, wind and sea-state data for oil & gas
installations from open, keyless APIs (Open-Meteo worldwide, MET Norway for
the Norwegian Continental Shelf, and the open Sodir facility register for
NCS installation name resolution).

See [SKILL.md](SKILL.md) for the full description, inputs/outputs and usage
pattern. Run the tests with:

```powershell
C:\appl\neqsim-venv\Scripts\python.exe -m pytest skills\environment\neqsim-weather-data\tests -q
```
