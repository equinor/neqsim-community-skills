# Standard Equipment Sizes

Public tables and helpers that round calculated sizes up to standard sizes: pipe NPS/DN (ASME B36.10M), API 526 relief-valve orifices, ASME B16.5 flange classes (ambient screen), typical IEC motor ratings, heat-exchanger tube lengths and vessel diameter fabrication steps.

Company and vendor sizes are not included; use the project datasheets or the enterprise overlay.

```bash
python -m pytest
python examples/round_to_standard_sizes.py
```
