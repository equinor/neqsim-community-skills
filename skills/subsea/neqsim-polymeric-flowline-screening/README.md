# Polymeric Flowline Screening

Educational screening of thermoplastic subsea flowlines against pressure,
external collapse, gas permeation, steady thermal performance and bend radius,
with missing evidence reported as data gaps rather than passes.

All material data (long-term strength, modulus, permeability, thermal
conductivity, design factors) is supplied by the caller from the manufacturer or
a qualification programme; this skill contains no material database. It is a
screening aid and not a qualification. A qualified pipe engineer must review.

## Install

```bash
pip install -e .[test]
```

## Run the tests

```bash
python -m pytest
```

See `SKILL.md` for inputs, outputs, engineering method, validation checklist and
limitations.
