# Jurisdiction and Regulatory Basis

Public orientation profiles (authorities, laws, regulation families, recognised standards, fiscal note, data sources) for Norway, the United Kingdom, the United States, Brazil and the EU baseline, plus a helper that builds the `jurisdiction_basis.v1` block a study records in `results.json` assumptions and data gaps.

The profiles contain no clause text and no proprietary material. Always verify against the authority source before stating compliance.

```bash
python -m pytest
python examples/basic_jurisdiction_block.py
```
