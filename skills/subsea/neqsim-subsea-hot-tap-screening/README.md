# Subsea Hot-Tap Screening

Educational screening of a mechanical-clamp hot tap on a live subsea pipeline:
branch-to-run ratio, tee pressure and temperature rating, remaining wall against
a hoop minimum, line velocity during cutting, hydrate margin and branch bending
moment. Missing evidence is reported as data gaps, never as a pass.

This skill supports screening only. Hot-tap procedure, clamp qualification,
welding (topside) and the pressure-containing design belong to the hot-tap
contractor and the governing standard. A qualified engineer must review the result.

## Install

```bash
pip install -e .[test]
```

## Run the tests

```bash
python -m pytest
```

See `SKILL.md` for inputs, outputs, engineering method, validation checklist and
limitations.
